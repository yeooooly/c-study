# 07. 구조체 (struct) + 동적 할당 (malloc)

이름 / 나이 / 키 / 자기소개를 하나의 구조체로 묶고, 자기소개는 `malloc` 으로 메모리를 받아 입력받은 내용 정리

## 1. 예제

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

struct profile
{
    char name[20];
    int age;
    double height;
    char* intro;
};

int main(void)
{
    struct profile yuni;

    strcpy(yuni.name, "ronaldo");
    yuni.age = 41;
    yuni.height = 187;

    yuni.intro = (char*)malloc(80);
    printf("introduce : ");
    gets_s(yuni.intro, 80);

    printf("name : %s\n", yuni.name);
    printf("age : %d\n", yuni.age);
    printf("Height : %.1lf\n", yuni.height);
    printf("introduction : %s\n", yuni.intro);
    free(yuni.intro);

    return 0;
}
```

## 3. 구조체

서로 다른 자료형의 변수를 **하나로 묶어서** 새로운 자료형을 만드는 것

```c
struct profile
{
    char name[20];    // 문자열 (배열)
    int age;          // 정수
    double height;    // 실수
    char* intro;      // 포인터 → malloc 으로 받은 메모리 주소 저장
};
```

| 구분 | 코드 | 의미 |
|---|---|---|
| 구조체 정의 | `struct profile { ... };` | 자료형 설계도 (메모리 할당 X) |
| 구조체 변수 선언 | `struct profile yuni;` | 실제 메모리 할당 |
| 멤버 접근 | `yuni.age = 17;` | `변수명.멤버명` → `.` 연산자 |

- `name` 은 배열 → `yuni.name = "ronaldo";` 처럼 `=` 로 넣을 수 없음 → `strcpy` 사용
- `age`, `height` 는 일반 변수 → `=` 로 바로 대입

## 4. malloc / free

```c
yuni.intro = (char*)malloc(80);   // 80 Byte 메모리 할당 → 시작 주소를 intro 에 저장
...
free(yuni.intro);                 // 다 쓰고 나면 메모리 반납
```

- `malloc` 은 `void*` 를 반환 → `(char*)` 로 형변환해서 저장 ([02. 형변환](./02_형변환_캐스팅.md) 참고)
- `name` 은 크기가 20 으로 고정, `intro` 는 **실행 중에** 필요한 만큼 메모리를 받음
- `malloc` 으로 받은 메모리는 `free` 로 반드시 반납

---

## 5. 사용한 함수

| 함수 | 헤더 | 역할 |
|---|---|---|
| `strcpy(목적지, 원본)` | `<string.h>` | 문자열 복사 |
| `malloc(크기)` | `<stdlib.h>` | 메모리 동적 할당 |
| `free(포인터)` | `<stdlib.h>` | 할당받은 메모리 반납 |
| `gets_s(버퍼, 크기)` | `<stdio.h>` | 한 줄 입력 (공백 포함), 최대 `크기 - 1` 글자 |

- `%.1lf` → `double` 을 소수점 1자리로 출력 ([03. printf 서식 지정자](./03_printf_서식지정자.md) 참고)
- `_CRT_SECURE_NO_WARNINGS` → Visual Studio 에서 `strcpy` 사용 시 나는 C4996 오류 방지
