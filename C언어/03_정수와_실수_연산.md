# 03. 정수 연산과 실수 연산

> **정수끼리 계산하면 정수, 실수끼리 계산하면 실수, 섞이면 실수**

| 연산 | 결과 | 예시 |
|---|---|---|
| 정수 ○ 정수 | **정수** | `7 / 2` → `3` |
| 실수 ○ 실수 | **실수** | `7.0 / 2.0` → `3.5` |
| 정수 ○ 실수 (섞임) | **실수** | `7 / 2.0` → `3.5` |

섞여 있으면 계산하기 전에 정수가 **자동으로 실수로 바뀝니다** (자동 형변환).

## `%`(나머지)는 정수끼리만

```c
int r = 7 % 2;      // 1
// 7.0 % 2          // 컴파일 오류!
```

## 결과를 넣는 변수의 자료형도 중요

계산은 **오른쪽 식의 자료형대로 먼저** 끝나고, 그다음에 **왼쪽 변수의 자료형에 맞춰** 바뀝니다.

```c
int   x = 7 / 2.0;   // 3.5로 계산 → int에 넣으면서 소수점이 잘려 3
float y = 7 / 2;     // 정수 나눗셈으로 먼저 3 → float에 넣어서 3.000000
float z = 7 / 2.0;   // 3.5로 계산 → 3.500000
```

## 정리

1. 정수끼리 나누면 소수점 아래는 **버려진다**.
2. 실수 결과가 필요하면 둘 중 하나라도 **실수로 만들어야** 한다. 예: `(float)a / b`, `7 / 2.0`
3. `%`는 정수에만 쓸 수 있다.
4. 대입할 때 변수의 자료형에 맞춰 한 번 더 바뀐다.
