# 02. 형변환 (캐스팅, Type Casting)

`(자료형)값` 형태로 쓰면 **그 식을 계산하는 순간에만** 값을 다른 자료형으로 바꿔서 사용합니다.

```c
int a = 10, b = 20;
float div;

div = (float)a / (float)b;   // 0.500000
```

- `a`와 `b`는 계속 `int`로 남아 있습니다. **변수 자체가 바뀌지 않습니다.**
- 이 줄에서만 `10` → `10.0`, `20` → `20.0`으로 바꾼 값을 꺼내서 계산합니다.

## 왜 필요한가?

C에서는 **정수끼리 나누면 결과도 정수**가 되고, 소수점 아래는 버려집니다.

| 코드 | 계산 | 결과 |
|---|---|---|
| `a / b` | 10 / 20 (정수 나눗셈) | `0` |
| `(float)a / (float)b` | 10.0 / 20.0 (실수 나눗셈) | `0.5` |

캐스팅을 하지 않으면 `div`에는 `0.000000`이 들어갑니다.

## 한쪽만 바꿔도 된다

```c
div = (float)a / b;   // 0.500000
```

피연산자 중 하나가 실수이면 나머지도 자동으로 실수로 바뀌어 계산됩니다.
(양쪽 모두 쓰면 의도가 더 잘 보입니다.)

## ⚠️ 괄호 위치 주의

```c
div = (float)(a / b);   // 0.000000
```

괄호 안의 **정수 나눗셈이 먼저** 끝나서 `0`이 되고, 그 `0`을 실수로 바꾼 것이라서 `0.0`이 됩니다.

## 예제

[examples/arithmetic.c](examples/arithmetic.c)

```c
#include <stdio.h>

int main(void)
{
    int a, b;
    int sum, sub, mul, inv, mod;
    float div;

    a = 10;
    b = 20;
    sum = a + b;
    sub = a - b;
    mul = a * b;
    div = (float)a / (float)b;
    mod = a % b;
    inv = -a;

    printf("a :%d, b=%d\n", a, b);
    printf("sum :%d\n", sum);
    printf("sub :%d\n", sub);
    printf("mul :%d\n", mul);
    printf("inv :%d\n", inv);
    printf("div :%f\n", div);
    printf("mod :%d\n", mod);

    return 0;
}
```

### 실행 결과

```
a :10, b=20
sum :30
sub :-10
mul :200
inv :-10
div :0.500000
mod :10
```

- `mod`가 `10`인 이유: 10을 20으로 나누면 몫이 0, 나머지가 10입니다.

## 정수 연산과 실수 연산

> **정수끼리 계산하면 정수, 실수끼리 계산하면 실수, 섞이면 실수**

| 연산 | 결과 | 예시 |
|---|---|---|
| 정수 ○ 정수 | **정수** | `7 / 2` → `3` |
| 실수 ○ 실수 | **실수** | `7.0 / 2.0` → `3.5` |
| 정수 ○ 실수 (섞임) | **실수** | `7 / 2.0` → `3.5` |

섞여 있으면 계산하기 전에 정수가 **자동으로 실수로 바뀝니다** (자동 형변환).

### `%`(나머지)는 정수끼리만

```c
int r = 7 % 2;      // 1
// 7.0 % 2          // 컴파일 오류!
```

### 결과를 넣는 변수의 자료형도 중요

계산은 **오른쪽 식의 자료형대로 먼저** 끝나고, 그다음에 **왼쪽 변수의 자료형에 맞춰** 바뀝니다.

```c
int   x = 7 / 2.0;   // 3.5로 계산 → int에 넣으면서 소수점이 잘려 3
float y = 7 / 2;     // 정수 나눗셈으로 먼저 3 → float에 넣어서 3.000000
float z = 7 / 2.0;   // 3.5로 계산 → 3.500000
```

### 정리

1. 정수끼리 나누면 소수점 아래는 **버려진다**.
2. 실수 결과가 필요하면 둘 중 하나라도 **실수로 만들어야** 한다. 예: `(float)a / b`, `7 / 2.0`
3. `%`는 정수에만 쓸 수 있다.
4. 대입할 때 변수의 자료형에 맞춰 한 번 더 바뀐다.
