# 02. 형변환 (캐스팅, Type Casting)

`(자료형)값` 형태로 쓰면 **그 식을 계산하는 순간에만** 값을 다른 자료형으로 바꿔서 사용합니다.

```c
int a = 10, b = 20;
float div;

div = (float)a / (float)b;   // 0.500000
```

- `a`와 `b`는 계속 `int`로 남아 있습니다. **변수 자체가 바뀌지 않습니다.**
- 이 줄에서만 `10` → `10.0`, `20` → `20.0`으로 바꾼 값을 꺼내서 계산합니다.

## 왜 필요한가?

C에서는 **정수끼리 나누면 결과도 정수**가 되고, 소수점 아래는 버려집니다.

| 코드 | 계산 | 결과 |
|---|---|---|
| `a / b` | 10 / 20 (정수 나눗셈) | `0` |
| `(float)a / (float)b` | 10.0 / 20.0 (실수 나눗셈) | `0.5` |

캐스팅을 하지 않으면 `div`에는 `0.000000`이 들어갑니다.

## 한쪽만 바꿔도 된다

```c
div = (float)a / b;   // 0.500000
```

피연산자 중 하나가 실수이면 나머지도 자동으로 실수로 바뀌어 계산됩니다.
(양쪽 모두 쓰면 의도가 더 잘 보입니다.)

## ⚠️ 괄호 위치 주의

```c
div = (float)(a / b);   // 0.000000
```

괄호 안의 **정수 나눗셈이 먼저** 끝나서 `0`이 되고, 그 `0`을 실수로 바꾼 것이라서 `0.0`이 됩니다.

## 예제

[examples/arithmetic.c](examples/arithmetic.c)

```c
#include <stdio.h>

int main(void)
{
    int a, b;
    int sum, sub, mul, inv, mod;
    float div;

    a = 10;
    b = 20;
    sum = a + b;
    sub = a - b;
    mul = a * b;
    div = (float)a / (float)b;
    mod = a % b;
    inv = -a;

    printf("a :%d, b=%d\n", a, b);
    printf("sum :%d\n", sum);
    printf("sub :%d\n", sub);
    printf("mul :%d\n", mul);
    printf("inv :%d\n", inv);
    printf("div :%f\n", div);
    printf("mod :%d\n", mod);

    return 0;
}
```

### 실행 결과

```
a :10, b=20
sum :30
sub :-10
mul :200
inv :-10
div :0.500000
mod :10
```

- `mod`가 `10`인 이유: 10을 20으로 나누면 몫이 0, 나머지가 10입니다.
