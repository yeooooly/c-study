## 1. 형변환이란

`(자료형)값` 형태 → **그 식을 계산하는 순간에만** 값을 다른 자료형으로 바꿔서 사용

```c
int a = 10, b = 20;
float div;

div = (float)a / (float)b;   // 0.500000
```

- `a`, `b` 는 계속 `int` → **변수 자체는 안 바뀜**
- 이 줄에서만 `10` → `10.0`, `20` → `20.0` 으로 바꾼 값을 꺼내서 계산

---

## 2. 왜 필요한가

C 에서는 **정수끼리 나누면 결과도 정수** → 소수점 아래는 버림

| 코드 | 계산 | 결과 |
|---|---|---|
| `a / b` | 10 / 20 (정수 나눗셈) | `0` |
| `(float)a / (float)b` | 10.0 / 20.0 (실수 나눗셈) | `0.5` |

#### 2.1 한쪽만 바꿔도 결과는 같음

```c
div = (float)a / b;   // 0.500000
```

피연산자 중 하나가 실수 → 나머지도 자동으로 실수로 바뀌어 계산 (양쪽 다 쓰면 의도가 더 잘 보임)

#### 2.2 괄호 위치 주의

```c
div = (float)(a / b);   // 0.000000
```

괄호 안 **정수 나눗셈이 먼저** 끝나서 `0` → 그 `0` 을 실수로 바꾼 것이라 `0.0`

---

## 3. 예제 : 캐스팅 O / X 비교

```c
#include <stdio.h>

int main(void)
{
    int a, b;
    int sum, sub, mul, inv, mod;
    float div, div_nocast;

    a = 10;
    b = 20;
    sum = a + b;
    sub = a - b;
    mul = a * b;
    div_nocast = a / b;          // 캐스팅 X: 정수 나눗셈으로 먼저 0이 됨 -> 0.0
    div = (float)a / (float)b;   // 캐스팅 O: 이 식에서만 실수로 바꿔 계산 -> 0.5
    mod = a % b;
    inv = -a;

    printf("a :%d, b=%d\n", a, b);
    printf("sum :%d\n", sum);
    printf("sub :%d\n", sub);
    printf("mul :%d\n", mul);
    printf("inv :%d\n", inv);
    printf("div (no cast) :%f\n", div_nocast);
    printf("div (cast)    :%f\n", div);
    printf("mod :%d\n", mod);

    return 0;
}
```

#### 3.1 실행 결과

```
a :10, b=20
sum :30
sub :-10
mul :200
inv :-10
div (no cast) :0.000000
div (cast)    :0.500000
mod :10
```

- **`div (no cast)` = `0.000000`** : `a / b` 는 정수끼리 나누기 → `10 / 20 = 0` 이 먼저 계산 → 그 `0` 을 `float` 에 넣어서 `0.000000`
- **`div (cast)` = `0.500000`** : `(float)` 로 실수끼리 나누기 → `10.0 / 20.0 = 0.5`
- `mod` = `10` : 10 ÷ 20 → 몫 0, 나머지 10

## 4. 정수 연산 vs 실수 연산

> **정수끼리 계산하면 정수, 실수끼리 계산하면 실수, 섞이면 실수**

| 연산 | 결과 | 예시 |
|---|---|---|
| 정수 ○ 정수 | **정수** | `7 / 2` → `3` |
| 실수 ○ 실수 | **실수** | `7.0 / 2.0` → `3.5` |
| 정수 ○ 실수 (섞임) | **실수** | `7 / 2.0` → `3.5` |

섞여 있으면 계산 전에 정수가 **자동으로 실수로 바뀜** (자동 형변환)

#### 4.1 `%` (나머지) 는 정수끼리만

```c
int r = 7 % 2;      // 1
// 7.0 % 2          // 컴파일 오류!
```

#### 4.2 결과를 넣는 변수의 자료형도 중요

오른쪽 식의 자료형대로 **먼저 계산** → 왼쪽 변수의 자료형에 맞춰 **한 번 더 변환**

```c
int   x = 7 / 2.0;   // 3.5로 계산 → int에 넣으면서 소수점이 잘려 3
float y = 7 / 2;     // 정수 나눗셈으로 먼저 3 → float에 넣어서 3.000000
float z = 7 / 2.0;   // 3.5로 계산 → 3.500000
```

---

## 5. 정리

1. 정수끼리 나누면 소수점 아래는 **버림**
2. 실수 결과가 필요하면 둘 중 하나라도 **실수로 바꿔야 함** → `(float)a / b`, `7 / 2.0`
3. `%` 는 정수에만 사용 가능
4. 대입할 때 변수의 자료형에 맞춰 한 번 더 바뀜
