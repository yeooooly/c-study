# 05. 구구단 (이중 for문)

`for` 안에 `for` 를 넣은 이중 반복문으로 1단 ~ 9단 구구단을 출력한 내용 정리

- 예제 코드 : [examples/gugudan.c](./examples/gugudan.c)

---

## 1. 예제

```c
#include <stdio.h>

int main(void)
{
    for (int a = 1; a < 10;a++) {
        for (int b = 1; b < 10;b++) {
            printf("%d * %d = %d\n", a, b, a * b);
        }
    }

    return 0;
}
```

---

## 2. 동작

- 바깥 `for` (`a`) : 단 → 1 ~ 9
- 안쪽 `for` (`b`) : 곱하는 수 → 1 ~ 9
- `a` 가 1 증가할 때마다 안쪽 `for` 가 **처음부터 9번** 다시 반복 → 총 9 × 9 = **81줄** 출력
- `a < 10` → 10 은 포함 안 됨 (1 ~ 9)
