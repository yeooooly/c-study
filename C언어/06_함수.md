## 1. 예제

```c
#include <stdio.h>

int sum(int x, int y);
int sub(int x, int y);
int mul(int x, int y);

int main(void)
{
    int a = 10, b = 20;
    int result;

    result = sum(a, b);
    printf("result : %d\n", result);

    result = sub(a, b);
    if (result >= 0)
        printf("result : %d\n", result);
    else
        printf("negative result : %d\n", result);

    result = mul(a, b);
    printf("result : %d\n", result);

    return 0;
}

int sum(int x, int y)
{
    int temp;
    temp = x + y;
    return temp;
}

int sub(int x, int y)
{
    int temp;
    temp = x - y;

    if (temp >= 0) return temp;
    else return -1;
}

int mul(int x, int y)
{
    int temp;
    temp = x * y;
    return temp;
}
```

## 2. 함수 구조

| 구분 | 위치 | 예시 |
|---|---|---|
| **선언** (원형, prototype) | `main` 위 | `int sum(int x, int y);` |
| **호출** | `main` 안 | `result = sum(a, b);` |
| **정의** | `main` 아래 | `int sum(int x, int y) { ... }` |

- 정의가 `main` 아래에 있음 → `main` 위에 **선언을 먼저** 해야 컴파일러가 함수를 알 수 있음
- `int sum(...)` 의 앞 `int` = **반환형** → `return` 으로 돌려주는 값의 자료형
- 호출할 때 `a`, `b` 값이 **복사**되어 `x`, `y` 로 들어감 → 함수 안에서 `x`, `y` 를 바꿔도 `a`, `b` 는 그대로
- `temp` 는 함수 안에서만 쓰는 **지역 변수** → 함수가 끝나면 사라짐

## 3. sub 함수의 return

```c
if (temp >= 0) return temp;
else return -1;
```

- 결과가 0 이상 → 실제 값 그대로 반환
- 결과가 음수 → 실제 값 대신 **`-1` 반환**
- `a - b` = `10 - 20` = `-10` → 음수라서 `sub` 는 `-1` 을 반환 → `main` 에서 `negative result` 쪽으로 출력
