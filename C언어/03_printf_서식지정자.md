## 1. 정수형 출력

| 서식 지정자 | 의미 | 예시 |
|---|---|---|
| `%d` | 10진수 부호 있는 정수 | `printf("%d", 123)` → `123` |
| `%i` | 10진수 부호 있는 정수 (printf 에서는 `%d` 와 동일) | `printf("%i", 123)` → `123` |
| `%u` | 부호 없는 10진수 정수 | `printf("%u", 123)` → `123` |
| `%o` | 8진수 정수 | `printf("%o", 15)` → `17` |
| `%x` | 16진수 정수 (소문자) | `printf("%x", 255)` → `ff` |
| `%X` | 16진수 정수 (대문자) | `printf("%X", 255)` → `FF` |

---

## 2. 실수형 출력

| 서식 지정자 | 의미 | 예시 (값 3.4) |
|---|---|---|
| `%f` | 소수점 형식으로 출력 | `3.400000` |
| `%lf` | printf() 에서는 `%f` 와 동일 | `3.400000` |
| `%e` | 지수 형식 (소문자) | `3.400000e+00` |
| `%E` | 지수 형식 (대문자) | `3.400000E+00` |
| `%g` | `%f` 또는 `%e` 중 적절한 형식 선택 | `3.4` |
| `%G` | `%g` 와 유사, 지수에 대문자 사용 | `3.4` |

> `%lf` 는 printf 에서는 `%f` 와 같지만, **scanf 로 `double` 을 입력받을 때는 반드시 `%lf`** 를 써야 함

## 3. 문자 및 문자열 출력

| 서식 지정자 | 의미 | 예시 |
|---|---|---|
| `%c` | 문자 출력 | `A` |
| `%s` | 문자열 출력 | `Hello` |
| `%p` | 포인터 주소 출력 | `0x...` |

---

## 4. 기타 서식 지정자

| 서식 지정자 | 의미 |
|---|---|
| `%%` | `%` 문자 자체를 출력 |
| `%ld` | `long` 정수 출력 |
| `%lld` | `long long` 정수 출력 |
| `%hd` | `short` 정수 출력 |
| `%zu` | `size_t` 자료형 출력 (`sizeof` 결과 등) |

---

## 5. 소수점 자릿수 지정하기

`%.자릿수f` → 소수점 이하 자릿수 지정 (기본값 6자리)

| 서식 지정자 | 의미 | 출력 예시 (값 3.4) |
|---|---|---|
| `%f` | 소수점 이하 6자리 | `3.400000` |
| `%.1f` | 소수점 이하 1자리 | `3.4` |
| `%.2f` | 소수점 이하 2자리 | `3.40` |
| `%.3f` | 소수점 이하 3자리 | `3.400` |
| `%.5f` | 소수점 이하 5자리 | `3.40000` |
| `%.10f` | 소수점 이하 10자리 | `3.4000000000` |
