# 01. 이스케이프 시퀀스 (Escape Sequence)

## 예제

[examples/escape.c](examples/escape.c)

```c
#include <stdio.h>

int main(void)
{
    printf("Be happy\n");
    printf("12345678901234567890\n");
    printf("My\tfriend\n");
    printf("Goot\bd\tchance\n");
    printf("Cow\rW\a\n");
    return 0;
}
```

### 실행 결과

```
Be happy
12345678901234567890
My      friend
Good    chance
Wow
```
