# 01. 이스케이프 시퀀스 (Escape Sequence)

문자열 안에서 `\`(역슬래시)와 그 뒤의 글자 하나가 합쳐지면 **특수한 동작을 하는 문자 1개**가 됩니다.
Visual Studio는 이 부분을 일반 글자와 **다른 색으로 표시**합니다. 오류가 아니라 정상입니다.

## 주요 이스케이프 시퀀스

| 코드 | 이름 | 하는 일 |
|---|---|---|
| `\n` | 줄바꿈 (new line) | 다음 줄로 넘어감 |
| `\t` | 탭 (tab) | 탭 간격만큼 띄움 |
| `\b` | 백스페이스 (backspace) | 커서를 한 칸 뒤로 옮김 |
| `\r` | 캐리지 리턴 (carriage return) | 커서를 그 줄의 맨 앞으로 옮김 |
| `\a` | 경고음 (alert) | "띵" 소리 (환경에 따라 안 날 수 있음) |
| `\\` | 역슬래시 | `\` 문자 자체를 출력 |
| `\"` | 큰따옴표 | `"` 문자 자체를 출력 |

## 예제

```c
#include <stdio.h>

int main(void)
{
    printf("Be happy\n");
    printf("12345678901234567890\n");
    printf("My\tfriend\n");
    printf("Goot\bd\tchance\n");
    printf("Cow\rW\a\n");
    return 0;
}
```

### 실행 결과

```
Be happy
12345678901234567890
My      friend
Good    chance
Wow
```

## 설명

- **`"My\tfriend"`**: `My`와 `friend` 사이가 탭 간격만큼 띄워집니다.
- **`"Goot\bd\tchance"`**
  1. `Goot` 출력
  2. `\b`로 커서가 한 칸 뒤(`t` 위치)로 이동
  3. `d`가 `t`를 덮어써서 `Good`이 됨
  4. `\t`로 탭을 넣은 뒤 `chance` 출력
- **`"Cow\rW\a"`**
  1. `Cow` 출력
  2. `\r`로 커서가 줄 맨 앞(`C` 위치)으로 이동
  3. `W`가 `C`를 덮어써서 `Wow`가 됨
  4. `\a`로 경고음

> `\b`와 `\r`은 글자를 지우는 것이 아니라 **커서만 옮기는 것**입니다.
> 그 자리에 새 글자를 출력하면 기존 글자가 덮어써집니다.
