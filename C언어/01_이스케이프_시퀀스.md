# 01. 이스케이프 시퀀스 (Escape Sequence)

`printf` 문자열 안에서 `\` + 문자 로 특수 동작을 넣어 본 내용 정리

- 예제 코드 : [examples/escape.c](./examples/escape.c)

---

## 1. 예제

```c
#include <stdio.h>

int main(void)
{
    printf("Be happy\n");
    printf("12345678901234567890\n");
    printf("My\tfriend\n");
    printf("Goot\bd\tchance\n");
    printf("Cow\rW\a\n");
    return 0;
}
```

---

## 2. 실행 결과

```
Be happy
12345678901234567890
My      friend
Good    chance
Wow
```
