# 04. 자료형 크기 : PC vs STM32F411

Windows PC / Linux PC / STM32F411 에서 C 자료형 크기 비교 정리

- 단위 : Byte (1 Byte = 8 bit), 일반적인 ABI 기준

---

## 1. 자료형 크기 비교

| 자료형 | Windows PC (64bit) | Linux PC (64bit) | STM32F411 (32bit) |
|---|:---:|:---:|:---:|
| `char` | 1 | 1 | 1 |
| `short` | 2 | 2 | 2 |
| `int` | 4 | 4 | 4 |
| `long` | **4** | **8** | **4** |
| `long long` | 8 | 8 | 8 |
| `float` | 4 | 4 | 4 |
| `double` | 8 | 8 | 8 |
| `long double` | **8** | **16** | 보통 8 또는 컴파일러 의존 |
| 포인터 `*` | **8** | **8** | **4** |

---

## 2. 차이 나는 부분

- **`long`** : Windows → 4, Linux → 8, STM32 → 4
  → 같은 64bit PC 라도 OS 마다 다름
- **`long double`** : Windows → 8, Linux → 16, STM32 → 컴파일러 의존
- **포인터** : 64bit PC → 8, 32bit STM32 → 4
  → 주소 크기 = CPU 비트 수 (64bit = 8 Byte, 32bit = 4 Byte)

> 크기가 정확히 몇 Byte 인지 중요할 때(레지스터, 통신 데이터 등)는 `<stdint.h>` 의 `int8_t` `int16_t` `int32_t` `uint32_t` 같은 **고정 크기 자료형** 사용

---

## 3. 예제 : sizeof 로 직접 확인

```c
#include <stdio.h>

int main(void)
{
    printf("char        : %zu\n", sizeof(char));
    printf("short       : %zu\n", sizeof(short));
    printf("int         : %zu\n", sizeof(int));
    printf("long        : %zu\n", sizeof(long));
    printf("long long   : %zu\n", sizeof(long long));
    printf("float       : %zu\n", sizeof(float));
    printf("double      : %zu\n", sizeof(double));
    printf("long double : %zu\n", sizeof(long double));
    printf("pointer     : %zu\n", sizeof(int *));

    return 0;
}
```

#### 3.1 실행 결과 (Windows PC, Visual Studio x64)

```
char        : 1
short       : 2
int         : 4
long        : 4
long long   : 8
float       : 4
double      : 8
long double : 8
pointer     : 8
```

- `sizeof` 결과는 `size_t` 자료형 → `%zu` 로 출력 ([03. printf 서식 지정자](./03_printf_서식지정자.md) 참고)
